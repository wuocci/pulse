# Pulse

An API that collects open data about public transport, roads, weather and street works, and tells you what's going on around a place or along a trip.

Starting with the Helsinki capital region.

**Status:** early development.

## Data sources

- [HSL / Digitransit](https://digitransit.fi/en/developers/)
- [Fintraffic Digitraffic](https://www.digitraffic.fi/en/)
- [Finnish Meteorological Institute](https://en.ilmatieteenlaitos.fi/open-data)
- [City of Helsinki](https://hri.fi/en_gb/)

## Development

Requires Node 24+ and pnpm 10.

```bash
pnpm install
```
