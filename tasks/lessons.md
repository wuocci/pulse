# Lessons

Corrections from the maintainer. Read at session start (`AGENTS.md`).

- **Don't commit before the maintainer validates the changes.** Leave work uncommitted, report what changed, and commit only after an explicit go-ahead. Amending or rewriting commits counts as committing. Pushing needs its own go-ahead.
- **No AI attribution in commits.** Never add `Co-Authored-By: Claude …` or similar trailers to commit messages.
